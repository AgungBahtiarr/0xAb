Selected projects

Four things I built

01 / 04

0xProxy Gateway

A reverse proxy and API gateway built for low latency. It handles request throttling, Redis-backed rate limiting, SSL termination and dynamic upstream routing.

Go, Redis, Reverse proxy, DevOps. GitHub

02 / 04

KubeWatch Dashboard

A web interface for watching Docker containers and Kubernetes clusters. It shows memory leaks, container crashes and a live log stream over WebSockets.

TypeScript, Astro, WebSockets, Docker. GitHub

03 / 04

ShellVault CLI

A command-line tool that organizes, encrypts and syncs SSH config profiles and keyrings across machines, with auto-completion and config verification.

Python, Bash, Cryptography, CLI. GitHub

04 / 04

LogSieve Aggregator

A low-overhead syslog collector written in Rust. It filters and indexes entries as they arrive, then sends warnings and errors to PostgreSQL and email.

Rust, Syslog, PostgreSQL, Linux. GitHub
