Saya Agung Bahtiar, lulusan D4 TRPL Politeknik Negeri Banyuwangi. Saat ini saya bekerja sebagai **Software Engineer** sekaligus **Network Engineer (NOC)** di salah satu ISP di Banyuwangi.

Di sisi jaringan, saya menangani routing Layer 2 dan Layer 3 pada perangkat **MikroTik**, **Huawei**, dan **Juniper** agar koneksi pelanggan tetap stabil. Saya juga mengelola layanan inti seperti DNS dan web server di atas **Debian** (bare-metal maupun **Proxmox**) menggunakan **Docker**.

Di sisi perangkat lunak, saya membangun aplikasi web dengan **Svelte**, **Astro**, dan **Hono**, didukung **PHP**, **Python**, dan **PostgreSQL**. Sistem yang saya buat mencakup billing mitra ISP terintegrasi MikroTik, aplikasi general ledger, alert jaringan otomatis, model ML untuk jalur redundan Layer 2, dan aplikasi native manajemen OLT dengan **Native Shell (NSH)**.
